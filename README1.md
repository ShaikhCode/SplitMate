# Android APK

Place the built Android release APK in this folder with this exact filename:

```text
SplitMate.apk
```

The website's Android download button points to `./apk/SplitMate.apk` and is enabled when the file is available on the hosted site.

Do not add signing keystores, passwords, or private credentials to this folder. Only commit the APK you intend to distribute publicly.
